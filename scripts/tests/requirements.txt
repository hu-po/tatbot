# Dependency set for the scripts/ test suite.
#
# This file exists because the set used to live only in a hand-typed command in
# AGENTS.md, and that command was wrong: it installed pytest/numpy/scipy and
# nothing else, so nine modules failed to import and the suite never ran green.
# A declared set can be fixed once; an incantation gets re-typed wrong.
#
# scripts/tests/conftest.py derives what each module imports and skips
# what is absent in the light profile. The full offline profile requires every
# declared dependency (except the separately provisioned LeRobot integration).

-r requirements-light.txt

# Fiducial/vision tests: ee_fiducial, ee_tracker_io, fiducial_inventory.
opencv-python-headless==5.0.0.93

# Metric RGB-D and original-material comparison tests. Match the offline
# benchmark environment. Use Python 3.12 for the Open3D wheel set. Distortion
# deprojection is a numpy port pinned by a checked-in SDK table, so the
# RealSense wheel is not a test dependency.
open3d==0.19.0
threadpoolctl==3.6.0

# LeRobot dataset-layout tests: train_dataset, train_depth_encoding.
pyarrow

# Policy/checkpoint tests: train_offline_eval, train_sampler, train_tb_bridge.
# Large (~2.5 GB with CUDA wheels). `scripts/check tests --light` omits it.
torch

# train_tb_bridge reads back what the TensorBoard logger wrote.
tensorboard

# test_stencil_rerun logs display caps into a recording spy; the version is the
# one fleet-wide pin (python/lerobot_robot_tatbot/pyproject.toml).
rerun-sdk==0.36.0

# NOT listed, deliberately: lerobot. train_dataset, train_depth_encoding and

# suite's throwaway environment for integration modules. conftest.py skips them and
