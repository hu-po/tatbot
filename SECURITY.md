# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately — do not open a public issue.

- Preferred: [GitHub private vulnerability reporting](https://github.com/hu-po/tatbot/security/advisories/new)
- Email: hello@tatbot.ai

We will acknowledge reports within a few days. Please include a reproduction
where possible.

## Scope

The latest release on `main` is supported. Reports about the archived
[tatbot-legacy](https://github.com/hu-po/tatbot-legacy) repository are out of
scope — it is unmaintained.

## Safety

tatbot involves software that can command physical hardware. If you find a
path by which the software could move hardware without an explicit, complete
hardware profile — or bypass an e-stop or fail-closed gate — treat it as a
security report and use the private channel above.
