# Security Policy

Report vulnerabilities privately — do not open a public issue.

- Preferred: [GitHub private vulnerability reporting](https://github.com/hu-po/tatbot/security/advisories/new)
- Email: hello@tatbot.ai

Include a reproduction where possible. The latest release on `main` is
supported.

tatbot includes software that can command physical hardware. A path by which
software could move hardware without an explicit, complete hardware profile —
or bypass an e-stop or fail-closed gate — is a security issue; use the private
channel above.
