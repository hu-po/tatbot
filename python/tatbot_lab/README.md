# tatbot-lab

The lab's library: studies and their trials (`store`, `propose`), what a trial can vary and where it takes effect
(`space`), cells on a dense tag print and the order to spend them (`tile`), each technique's test pattern
(`patterns`), proposed trials into runs, programs and cell manifests (`plan`), and the readers that measure a
drawn cell from the rig's own frames (`read`). Run it as `tatbot lab`; the behaviour and limits are in
`docs/lab.md`.
